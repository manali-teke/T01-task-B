# Grade calculator requirements

| ID | Field or behavior | Requirement |
| --- | --- | --- |
| R1 | Homework average | Required. A score from 0 to 100, with up to 2 decimal places (for example 87.25). |
| R2 | Midterm exam | Required. Same rule as R1. |
| R3 | Final exam | Required. Same rule as R1. |
| R4 | Extra credit | Optional. If given, a whole number of points from 0 to 5. |
| R5 | Note | Optional free text, up to 120 characters, for the student's own reminder. Show a live character counter. |
| R6 | Errors | Show each error next to its field. Keep everything the user typed so they can fix it. |
| R7 | Result | Final grade = 40% homework + 25% midterm + 35% final exam, plus extra credit points, capped at 100. Show it to one decimal place with the letter grade (A for 90 and above, B for 80 and above, C for 70 and above, D for 60 and above, F below 60) and the note exactly as typed, as plain text. |
